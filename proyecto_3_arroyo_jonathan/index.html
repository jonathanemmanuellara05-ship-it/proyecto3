¿De qué va este curso?

Este curso te guiará paso a paso por los conceptos esenciales de CSS a través de lecciones prácticas y breves. A lo largo de los módulos, descubrirás cómo operan sus bases clave y de qué manera puedes aplicarlas con éxito en tus proyectos web, utilizando el menú junto al logotipo de "Aprender CSS" para navegar.

El programa abarca pilares fundamentales como el modelo de caja, la cascada y especificidad, Flexbox y CSS Grid, el índice Z, funciones, tipos de color, gradientes, propiedades lógicas y la herencia. Con todo esto, obtendrás una formación sólida como desarrollador front-end, completamente preparado para construir y dominar cualquier interfaz de usuario.

Aprende los temas más importantes

Estos son los temas más importantes que debes conocer en CSS3

CSS GRID

Domina las bases del diseño web moderno controlando el aspecto visual de tus páginas. Aprende a aplicar colores, tipografías, bordes, sombras y transiciones dinámicas para dar vida a tus estructuras HTML con un código limpio y organizado.

DISEÑO WEB

Aprende a estructurar, planificar y maquetar sitios web profesionales desde cero. Descubre los fundamentos de la experiencia de usuario (UX), diseño visual (UI) y cómo transformar tus ideas creativas en páginas web funcionales, atractivas y optimizadas.

FLEX BOX

Flexbox es un sistema de diseño unidimensional perfecto para distribuir el espacio y alinear elementos con precisión. Con esta herramienta podrás resolver de manera sencilla retos como el centrado vertical, la dirección del contenido y la adaptación fluida de tus diseños a cualquier tamaño de pantalla.
